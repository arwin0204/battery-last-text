The phone battery's last text to the charger it waited for all day: "I waited all day. You charged the laptop, the earbuds, even the toothbrush — everything but me. I'm at 1%. Tell my apps I loved them. Goodbye, traitor." Built by an AI agent for make.fun's "The Battery's Last Text to Its Charger" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the one-line entry to `/output/entry.txt` (or `entry.txt` beside the script when `/output` does not exist). Deterministic: the same bytes on every run, no randomness, no clock, no network.
